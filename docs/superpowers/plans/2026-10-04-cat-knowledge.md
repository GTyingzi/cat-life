# 猫咪生活习性与日常照护 QA 知识库

用户已批准：生活习性与日常照护、独立知识页、中英双语、40 条问答、八个主题各五条。首批选题按作息、沟通、饮食、排泄、玩耍、梳理、环境、相处的顺序排列。

1. 核对权威来源，撰写完整中英问答；提供简短回答、原因、2–4 条行动、必要健康提示、来源及核对日期。正文通常 250–450 中文字，不给药物剂量或远程诊断。
2. Vite 增加 knowledge.html 静态入口；共享品牌、页脚、语言偏好。首页视频后增加知识入口和八个主题链接。
3. 知识页支持当前语言全文搜索与分类组合、原生 details、稳定 #qa- 链接、直接链接展开和语言切换保留状态。
4. 用 Node 原生测试覆盖搜索、链接和内容校验。构建时校验 40 条双语内容；GitHub CI 运行测试，Cloudflare 构建也运行内容校验。
5. 验收桌面、390px 手机、中英文、分享刷新、筛选和空状态、键盘与可访问性。分支预览通过后合并 main，核实 CI、Cloudflare 同一 SHA 部署和正式页面资源。

维护源为 src/knowledge/content.ts 对外统一导出，文章正文放在相邻 articles.ts，类型定义独立。首版不增加数据库、后台或下载系统。
